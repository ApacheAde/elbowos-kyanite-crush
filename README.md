# Kyanite Crush

Full-colour Python 3 neon asteroids arcade for ElbowOS.

Center ship rotates and fires. Shatter cyan / magenta / gold / lime shards that drift and split.
A/D or arrows rotate. Space fires. Up/W for light thrust. R restart.

## Play
```
pip install -r requirements.txt
python3 kyanite_crush.py --play
```

## Record a 9:16 reel
```
python3 kyanite_crush.py --record
```
Outputs KYANITE_CRUSH_ElbowOS.mp4 (1080x1920, 15s, 30fps).
